# FRAGCODER Documentation

## Overview

This directory contains technical documentation for FRAGCODER, a web application for creating, sharing, and discovering GLSL fragment shaders.

For getting started quickly, see:
- [SETUP.md](SETUP.md) - Installation and development setup
- [DEPLOYMENT.md](DEPLOYMENT.md) - Production deployment guide
- [../TESTING.md](../TESTING.md) - Testing guide (in project root)
